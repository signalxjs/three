# @sigx/three-rapier

[![npm](https://img.shields.io/npm/v/@sigx/three-rapier.svg?label=%40sigx%2Fthree-rapier&color=blue)](https://www.npmjs.com/package/@sigx/three-rapier)

[Rapier](https://rapier.rs) physics for [`@sigx/three`](../three): `<Physics>`,
`<RigidBody>`, `<Collider>`, collision and sensor events, auto-generated
colliders from mesh geometry, and a debug renderer — stepped on the fixed
timestep of the `@sigx/runtime-three` frame loop with interpolation.

> 🚧 Scaffold. The components land in the follow-up PRs tracked from
> [signalxjs/three#1](https://github.com/signalxjs/three/issues/1).

## Install

```bash
pnpm add @sigx/three-rapier @dimforge/rapier3d-compat
```
